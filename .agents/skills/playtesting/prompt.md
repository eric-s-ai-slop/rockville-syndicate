> Use `omega-agent-v1` JSON commands with a unique `cmd_id` for every meaningful action. Send exactly one newline-terminated JSONL command at a time and wait for its correlated `completed`/`failed` receipt. When a `visual_checkpoint` is emitted, stop, inspect its PNG with your image-viewing capability, and immediately send `reviewcheckpoint <id> clear|issue-found|inconclusive <observation-note>`. Every verdict, including `clear`, requires a concrete note about visible actors, layout, text, or UI; placeholders such as `skip`, `looks fine`, or `scene entered` are rejected. The CLI blocks progression while checkpoints are pending.
>
> `advance` always exits with a named `status` — respond per the skill's status table, never by improvising: `choice-present` → savestate, then take **every** option deliberately; `walk-target-present` → inspect `targets`, then `walkto` or held keys (real input, no teleports); `mode-active` → attempt the minigame normally before any bypass; `ambient-dialogue` → not a block, observe and continue; `chapter-ended` → verify the end state, then report.
>
> Never use `eval`, custom automation, `injectbeat`, `modify`, `mode`, `goto`, multi-beat `skipbeat`, or `chapterflag`/`settings` writes — `--playtest` blocks them all and every `watch`/`loadstate <file>`/`speed` use is recorded in `session_summary.audit`. There is no command named `_bypass` or `bypass`. The permitted bypass commands are exactly `skipbeat 1` for a proven stuck non-mode beat and `winmode`/`losemode` for a blocking foreground mode. Before a mode bypass, review its checkpoint and attempt the visible UI with normal input; never chain `skipbeat 1` through a minigame. Bypasses mark the run `partially-bypassed`. Capture evidence first and rerun the affected path naturally before claiming completion. If a command is rejected, quote the exact command and error; do not generalize it into a conflict between all bypasses and `--playtest`.
>
> Do not end after a minigame. Verify the post-mode sequence and the chapter's `endChapter` state at runtime. End with the required report format from the skill, including command IDs, evidence paths, coverage, `session_summary.playtest_integrity`, and `session_summary.visual_qa`; `visual_qa.pending` must be empty. A terminal beat with incomplete visual QA is not completion: `quit`/EOF fails closed and exits nonzero. Write the report to `qa/<chapter-id>/report.md` (the chapter's `id` from its config, e.g. `qa/spain_betrayal/report.md`); keep screenshots and other artifacts in `agent-artifacts/<chapter-id>/`.
